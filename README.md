# MonoBudget для Telegram

Власний Telegram-бот для тижневого й місячного бюджету витрат з **Monobank**: закріплений статус, звіти за категоріями, сповіщення. Працює в Docker на NAS, без відкритих портів.

> 🚧 Перша версія готується в pull request. Інструкції з розгортання з'являться тут разом із нею.
